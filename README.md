# THE FACILITY

You didn't download an app — you've been **enrolled**.

A dark-comedy Android app (iOS eventually): the user is Subject #50640 in a "Personal Enrichment Program" administered by **V.E.R.A.**, a deadpan, faux-supportive AI overseer. An ever-growing cabinet of weird sensor-driven "evaluations" — a compass that won't say where it's leading you, a support organism that eats your steps, a queue position that mostly goes down.
